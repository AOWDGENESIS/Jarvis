# JARVIS OMNI — Entwicklungsplan (B3)

## Vision
Ein vollstaendiges, lokales KI-System das sich wie echte Windows-Software
anfuehlt. Doppelklick — laeuft. Kein Terminal, kein Python-Wissen noetig.

## Abgeschlossene Phasen

### Phase 1: Fundament (Abgeschlossen)
- Ollama-Integration mit automatischer Modellsuche
- FastAPI-Backend mit 30+ Endpunkten
- Fusion UI (Sci-Fi HUD)
- Dual-Brain: qwen2.5:14b + deepseek-coder-v2

### Phase 2: Stabilisierung (Abgeschlossen)
- bat-Dateien auf reines ASCII (CP1252-kompatibel)
- Circuit-Breaker im Frontend
- Ehrliche Statusanzeige (LOADING/SATELLITE/EINSTEIN)
- Edge-TTS + pyttsx3 Fallback

### Phase 3: Features (Abgeschlossen)
- SQLite: Aufgaben + Gesprächsprotokoll
- Hotword-Erkennung
- Krisen-Modus (D7)
- Alpha-Protokoll (A5/D1)
- Develop-Modus (A8)
- Weltkarte (F4)
- Live-Graph (I4)

## Offene Phasen

### Phase 4: Windows-Test (AKTUELL)
- RUN_JARVIS.bat auf echtem Windows testen
- Edge-TTS Audio-Qualität pruefen
- Hotword mit echtem Mikrofon testen
- Erinnerungen nach Zeitablauf testen

### Phase 5: Zukunft
- K1: Echter .exe Installer (PyInstaller)

- Home Assistant Integration
